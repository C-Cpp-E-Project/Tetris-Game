## Tetris Game 🕹️

A classic *Tetris Game* built with Arduino and simulated using Proteus. The game features an 8x32 LED Matrix for dynamic block dropping, live score tracking on an LCD display, and real-time keyboard control via Serial Monitor.

### Features
* 🕹️ Classic Tetris mechanics on a tall 8x32 LED Matrix.
* ⚡ Real-time hardware simulation with responsive keyboard controls (`W`, `A`, `S`, `D`).
* 💡 Built-in game assist features: Toggle block placement shadow (`K`) and color modes (`L`).

### Files Included
* `1.ino` - The core Arduino source code.
* `1.pdsprj` - The Proteus simulation design file.

## Tetris เกม 🕹️

โปรเจกต์ *เกมตัวต่อเตตริส* พัฒนาโดยใช้บอร์ด Arduino และจำลองการทำงานของฮาร์ดแวร์ผ่านโปรแกรม Proteus แสดงผลชิ้นส่วนตัวต่อเคลื่อนที่บนหน้าจอ LED Matrix ขนาด 8x32 พร้อมระบบนับคะแนนโชว์บนจอ LCD และสั่งการเลี้ยว/หมุนบล็อกแบบ Real-time ผ่านคีย์บอร์ด

### ฟีเจอร์เด่น
* 🕹️ ระบบเกมเตตริสยอดฮิต แสดงผลบนหน้าจอ LED Matrix ขนาด 8x32 อย่างลื่นไหล
* ⚡ จำลองการทำงานของฮาร์ดแวร์แบบ Real-time ควบคุมง่ายผ่านปุ่มคอมพิวเตอร์ (`W`, `A`, `S`, `D`)
* 💡 ฟังก์ชันเสริมช่วยเล่น: เปิด/ปิดเงาช่วยเล็งตำแหน่งตก (`K`) และเปิด/ปิดสลับโหมดสีบล็อก (`L`)

### ไฟล์ในโปรเจกต์นี้
* `1.ino` - โค้ดหลักภาษา C/C++ สำหรับ Arduino
* `1.pdsprj` - ไฟล์จำลองวงจรและฮาร์ดแวร์ในโปรแกรม Proteus
